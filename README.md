## 🚀 Run Locally

### 1. Clone the Repository

```bash
git clone https://github.com/SAKETHHARKANCHI/SAKETHHARKANCHI.github.io.git
```

### 2. Navigate to the Project

```bash
cd SAKETHHARKANCHI.github.io
```

### 3. Install Dependencies

```bash
flutter pub get
```

### 4. Run the Portfolio

```bash
flutter run -d chrome
```

The website will open in Google Chrome.

---

## 🏗️ Build for Web

To create a production build of the Flutter website:

```bash
flutter build web --release
```

The generated files will be available inside:

```text
build/web/
```
